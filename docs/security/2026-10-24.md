# Security review, 24 Oct 2026

Internal review by the developer. No external audit. Version reviewed: 0.6.0 (Mac app, Android APK, local server,
relay 0.5.x as deployed). Grid: permissions, network, storage, cryptography.

## Permissions

- Android: `android.permission.INTERNET` only (`aapt2 dump permissions`), listed in `docs/permissions.txt` and checked by
  the CI against `godot/export_presets.cfg`, and by `tools/release-android.sh` against the built APK.
- Android: `allowBackup=false`, target SDK 36. Exported components: the launcher alias, and the androidx
  `ProfileInstallReceiver`, which requires the `DUMP` permission (shell only).
- Mac: ad hoc signature with the hardened runtime; the embedded server has its own entitlements
  (`tools/server.entitlements`).

## Network

- Local server: listens on 127.0.0.1 only, refuses any `Host` other than localhost and any `Origin` (no CORS), local
  token (0600) required for every route that changes state or reveals the chain.
- Relay: HTTPS through Traefik, per-IP and per-chain limits, blobs capped at 256 KiB, no IP address in its own log.
- Phone: relay address parsed strictly, http accepted only for a local network; Godot's own sockets are used, so the
  Android cleartext policy does not apply and the parser is the only guard.
- Updates: manifest and packages only from the manifest's origin under `/download/`, SHA-256 checked before the file is
  shown (Mac); Android installs only an APK with the same certificate.
- Detailed voices: off by default, need both the setting and the user's own key; 120 characters per sentence, daily cap.

## Storage

- Mac: data in `~/Library/Application Support/AImpire/`, files written atomically in 0600. The chain secret is in
  `config.json`, not in the Keychain.
- Android: settings and chain key in the app's private storage, not in the Keystore.
- Session logs are only read. The new erase route refuses to touch the session logs folder and any folder around it
  (tested in `daemon/test/erase.test.js`).

## Cryptography

- Sync chain: 128-bit secret, HKDF-SHA256 derived keys (encryption, MAC, write token), AES-256-CBC then HMAC-SHA256 over
  the IV and the ciphertext (encrypt then MAC), constant-time comparison, authenticated timestamp against replay, test
  vectors in `docs/SYNC-VECTEURS.json` checked by both the Node and the Godot implementations.

## Fixed in this release

- No way to erase everything: added "Erase everything" (Mac: data folder, game settings, chain deleted from the relay;
  Android: settings and chain key).
- No privacy screen in the app: added About and "What leaves your device", with the same facts as `PRIVACY.md`.
- A personal path in `docs/SYNC.md`: removed, and the CI now refuses macOS home paths.
- No published signing fingerprint: now in `SECURITY.md` and shown on the phone, read from the installed APK.

## Still open

- The update manifest is not signed (Ed25519 or minisign planned).
- The Mac app is not signed with a Developer ID nor notarized.
- The chain secret is not in the Keychain (Mac) or the Keystore (Android).
- The relay is not yet reachable over Tor and publishes no transparency report.
- Builds are not reproducible yet; releases are built on the developer's Mac, not in CI.
